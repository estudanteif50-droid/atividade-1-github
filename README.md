# Minha Atividade de Git e GitHub

Este projeto foi desenvolvido como atividade para praticar o uso do Git e GitHub.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Sobre o projeto

O projeto possui uma página HTML utilizando CSS e JavaScript.

Também possui uma pasta de imagens com três imagens utilizadas na página.

## Objetivo

Aprender a criar, alterar, adicionar e excluir arquivos utilizando o GitHub.
